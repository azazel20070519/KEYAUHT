# 🚀 GESTOR DE CLAVES CON GITHUB PAGES // CDR

Esta carpeta contiene tu propia plataforma web de licencias:

## 📁 Archivos Creados:
1. `index.html`: Panel web interactivo con diseño futurista morado idéntico al macro.
   - Genera claves limpias sin marcas de agua (formato `CDR-XXXX-XXXX` o el que tú elijas).
   - Selector de duración (1 día, 1 semana, 1 mes, 3 meses, 1 año, Lifetime).
   - Botón para **Pausar** y **Eliminar claves con 1 clic**.
   - Botón para **Copiar JSON** listo para guardar.
2. `licenses.json`: Archivo con la lista de claves activas y sus fechas de vencimiento.

---

## 🌐 Pasos para publicarlo gratis en GitHub Pages:

1. Ve a [github.com](https://github.com) y crea un nuevo repositorio público (ejemplo: `cdr-keys`).
2. Sube estos dos archivos (`index.html` y `licenses.json`).
3. En GitHub, ve a **Settings** ➔ **Pages** (en el menú izquierdo).
4. En **Branch**, selecciona `main` (o `master`) y dale a **Save**.
5. ¡Listo! En 1 minuto tendrás tu enlace activo:
   `https://TU_USUARIO.github.io/cdr-keys/`
   Y tu enlace directo de claves:
   `https://TU_USUARIO.github.io/cdr-keys/licenses.json`

Pega ese enlace en el macro y tendrás control total de tus claves desde cualquier teléfono o PC sin pagar un solo centavo.
